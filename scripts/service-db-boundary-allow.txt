#
# 格式：<键><TAB><理由>      （键 = 仓库相对路径#函数名；以 # 开头的整行是注释）
# 键与理由之间必须是**一个 TAB**（理由里可以有空格）。
#
# 纪律：
#   · 每条必须写明**具体理由** —— 这张表是给下一个读代码的人看的，不是给自己用的；
#   · 条目不再命中（已改成 model 具名方法 / 函数改名 / 被删）脚本会失败，必须删掉：
#     只增不减的清单等于没有门禁；
#   · **只有「确认不是违规」才进这张表**（句柄指向的不是本模块表 / 本来就是跨模块 …Tx 调用 /
#     语句不是表访问）。能改成 model 具名方法的一律改，不要拿豁免为「先把门禁刷绿」记账。
#   · 判据 ①b 覆盖事务句柄上的裸查询**全族**（.Model( / .Where( / .Create( / .Exec( …），
#     但仍是启发式：经 model 裸句柄的直查（如 publication 的 RouteDB(ctx)）、先取句柄存到
#     局部再用、.Session(...) 这类链式包装都扫不到 —— **清单为空不代表边界干净**。
#
