# 纪律：
#   · 只有「确认不是缺陷」才进这张表 —— 判据是**这个页面有没有列表语义**：
#     若空数据时用户仍需要知道「有哪些列 / 能按什么筛」，表头就必须在（照样板修）；
#     只有「整页就是一张引导、根本没有列表可看」才豁免。
#   · 条目不再命中（修好了 / 文件改名了）脚本会失败，必须删掉：
#     只增不减的清单等于没有门禁。
#   · 明确写清为什么这一页**不需要**表头，别写「暂不处理」。
