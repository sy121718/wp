# 页面写端点鉴权的豁免清单（scripts/check-page-endpoint-authz.py 的输入）
#
# 格式：<go 相对路径> <路由串> TAB <理由>
# 规则：只登记**确实不需要 Casbin 权限点**的端点；条目一旦不再命中，门禁就会失败
# （清单只增不减等于没有门禁）。
#
# 三类合法豁免：
#   1. 公开面 —— 无会话依赖，鉴权靠别的手段（验签 / 限流 / 逐能力白名单）；
#   2. 自助面 —— 组级 requireUser() 已强制登录，改的是调用者自己的东西，无跨用户面；
#   3. 只读/纯计算 —— 用 POST 传参但不写库不写产物，与所在页面同权。
#
# 与 check-permission-gaps.sh 的分工：那条门禁比「路由 ↔ 权限点」的缺口（只覆盖 /api），
# 这条覆盖页面组 —— 两者都不红，才说明写面鉴权完整。

# ---- 公开面 ----
internal/routers/routes.go accessUnlockPath	站点守卫解锁页：未登录访客唯一的自救入口，带 IP 限流（10 次/分钟）压 bcrypt 爆破成本
internal/module/runtimefragment/router.go /_fragments/:type	访客片段面：逐 capability 白名单 + 声明式认证策略（anonymous/session），写状态能力必须自带 CSRF
internal/module/analytics/inbound/http/analytics_router.go /analytics/collect	访客采集端点：控制面/访问面分离的明文例外
internal/module/cart/inbound/http/cart_router.go /payment/callback	支付网关回调：调用方不是后台用户，鉴权靠 HMAC 验签（失败只回四条业务 key）
internal/module/user/inbound/http/user_router.go /register	公开注册（访客自助开户）
internal/module/ai/inbound/http/ai_router.go /mcp	公开面（外部接入点）：调用方不是后台用户，而是持有对外访问令牌（PAT）的 MCP 客户端 —— 鉴权是「Bearer 令牌校验 + 令牌 scope ∩ 账号 Casbin 权限」两关（见 ai_mcp_endpoint.go），没有会话可挂。挂上 CasbinMiddlewareForPath 反而会把这唯一合法的调用方挡在外面
internal/module/user/inbound/http/user_router.go /resend	公开重发激活邮件（带敏感操作限流）
internal/module/user/inbound/http/user_router.go /login	访客登录（带敏感操作限流）
internal/module/user/inbound/http/user_router.go /logout	访客登出
internal/module/user/inbound/http/user_router.go /forgot	公开忘记密码（带敏感操作限流）
internal/module/user/inbound/http/user_router.go /reset	公开重置密码（带敏感操作限流）
cmd/builder/main.go /builder/generate	测试构建工具进程：cmd/builder 是独立于主服务的开发/测试辅助进程，不参与主路由装配
