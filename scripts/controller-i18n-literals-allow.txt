# 口径（改口径等于改门禁，脚本头与本文件各写一份）：
#   · 统计范围 `internal/module/<模块>/inbound/http/*.go`（**非** _test.go），跳过整行注释；
#   · 计数单位是 key 字面量的**出现次数**（`"<名字空间>.<子域>.<...>"`），不是文件数或行数；
#   · 只有 `down` 一种 mode：只允许下降；计数归零的条目**必须删行**（僵尸行会让测试失败）；
#   · 未登记的模块一旦出现字面量即失败 —— 新模块要么当场写干净，要么显式登记存量。

# 终局：控制器里不出现任何词条 key 字面量（key 一律来自 `internal/module/<模块>/enums/`）。
