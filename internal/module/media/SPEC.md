# media — 媒体库与产物引用集

## 职责

附件、文件分类、图片变体（内容指纹命名 + 不可变长缓存），以及「产物事实级引用集」：哪些产物引用了哪些媒体。

## 边界

- **零跨模块 import**：本模块不认识页面、实例或内容，换图后的影响面经 `StaleMarker` 端口交回引用方实现。
- **换图不删旧文件、不改扩展名与 URL**。
- **不吞掉通知失败**：通知不出去就报错，不能返回空集合（换图后不可见是用户可感知错误）。
- 引用集以编译后的 HTML 为准，由引用方在构建期同步。
