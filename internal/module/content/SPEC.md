# content — 内容实体与字段白名单

## 职责

内容实体（文章等，JSONB 数据）与其字段白名单，构建期数据解析（按实体与按集合），可翻译字段判据。

## 边界

- **字段白名单只此一处**：页面文档的绑定校验与内容模板的绑定校验共用本模块的白名单；两处各维护一份就是分叉。
- **构建期按语言一次预载**译文，不逐字段查库。
- 内容实体是业务事实，**不保存页面 AST**；页面结构归页面文档或内容模板。
- 需要公开详情 URL 的内容实体必须关联自动发布实例，禁止「内容 → 模板 → 访问时渲染」的路径。
