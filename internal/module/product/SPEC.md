# product — 商品与变体

## 职责

商品、变体、属性、分类、品牌、标签、评分、定价规则（调价单）与捆绑配置。构建期的商品数据源也在这里（按集合/按实体解析）。

商品级字段只是「新增变体时的默认值模板」。

## 边界

- **商品不存价**：价格只在变体上；商品级价格字段一律视为默认值。
- **不存库存真源**：可用量经 `inventory` 契约读；缓存字段只被同步与对账写。
- 不管订单、购物车、客户。
- 成本价不进构建期字段白名单。
- 本模块是分层判据的「范例模块」，零容忍门禁（展示字段 / 时间类型 / 取词 / 控制器取词）先在这里落地。
