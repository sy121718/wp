# contenttemplate — 内容实体类型的页面结构

## 职责

为内容实体类型（商品 / 文章 / 分类）定义版本化页面结构，每次构建参与派生快照。包含草稿与不可变版本、当前版本指针、结构模板角色（详情页 / 归档页 / 页眉页脚）。

## 边界

- **结构模板（页眉页脚）拒绝字段绑定**：页眉页脚不属于任何实体。
- **保存宽容、发布严格**：保存草稿用容错校验，发布与解析用严格校验。
- **不是运行时模板**：只参与构建期派生，访客请求不经过它。
- 作用域缺失时不做查询兜底：查不出就报空，不猜工程。
- 删除/改动的影响面经 `TemplateImpactPort` 交给调用方判断，本模块不判断页面是否还在用。
