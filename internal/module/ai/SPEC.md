# ai — 大模型接入

## 职责

模型配置（多协议驱动）、会话与事件、调用日志与工具调用日志、工具幂等键、访问令牌；流式与会话内的工具调用编排。

本模块只负责「配置 + 协议适配 + 统一调用」，不承担业务决策。

## 边界

- **密钥明文只存在于两个瞬间**：待加密入参与出站请求头；其余位置只有密文。
- SSRF 防护与 `webhook` 是**两份独立实现**（代码注释明写「同一口径的两份独立实现，模块间不跨依赖」）：防线是 DNS 解析后的 IP 而不是 hostname 字符串，每次出站重新校验。
- 展示层指令协议（统计 / 表格 / 列表 / 折叠块的封闭白名单）由 `internal/uispec` 定义，本模块只产出不带数据的指令，数字一律服务端查。
