流程只有一条：客户提交退货申请 → 管理员审核 → 先入库、后退款。 「入库」是把货加回库存（原因字典里的退货入库），入库成功之后系统才会退款。 顺序不能反 —— 反过来就是「钱退了、货没回来」，这是退货流程最容易被薅的地方， 所以这个页面没有「只退款」的按钮。

状态：待审核 → 已同意待收货 → 已入库待退款 → 已完成；已拒绝 / 已撤销是终态。 现实里货往往早就到了（客户先联系客服、客服再走系统），所以「同意」时可以勾选 同意并立即完成入库 + 退款（一步到底）。 「已入库待退款」是退款那一步没做完（通道抖动 / 网络断了）留下的状态，补退款即可，不会重复入库。
