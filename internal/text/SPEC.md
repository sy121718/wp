# text — 界面文案注入线

## 职责

把界面文案能力注入到页面与片段的数据根：语言、`t` / `tf` 取词函数、语言跳转。以及判定一个错误对外是哪个事实（`FactOf`），负责记日志。

## 边界

- **只注入，不取词**：本包不替任何人拼成品句；界面文案由模板调 `t` / `tf`，service 侧走它注入的取词函数。
- **无业务语义、不读模型**。
- 递归注入到嵌套数据，片段被 `include` 后仍能取词；漏注入是静默空串——这是本模块最容易静默失败的地方。
