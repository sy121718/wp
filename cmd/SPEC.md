# config 与 cmd — 进程装配与入口

## 职责

`config/` 负责配置读取与组件生命周期：组件按固定顺序初始化（日志 → 校验 → 数据库 → 迁移 → Casbin → i18n → 缓存 → 会话 → 上传 → 队列 → 验证码），任一关键组件失败即逆序关闭已初始化的组件并退出。

`cmd/` 是入口集合：主进程、独立构建器预览、迁移专用开关，以及若干只读运维命令。

## 边界

- **组件不决定进程退出**：`Init()` 只返回 error，由装配层决定。
- **迁移开关不改变权限同步**：跳过迁移只跳过结构与 seed，权限点 upsert 照跑；迁移专用模式不受开关约束。
- **运维命令默认只读**：破坏性动作必须显式加参数。
- **构建器预览入口独立**：只挂渲染器与预览路由，不依赖数据库、缓存与认证。
