## 一、设计目标 ✅

引入组织架构（部门），当前支持"总部 → 分公司 → 部门"无限级树形结构。部门归属通过 `sys_admin.dept_id` 字段存储，一个用户属于一个部门。

---

## 二、核心模型：四个正交概念 ✅

```
User ──N:1──→ Dept（属于某个部门）
User ──N:N──→ Role（拥有哪些角色）
Role ──N:N──→ Permission（拥有哪些权限）
```

部门唯一的权限语义：数据范围维度，不参与功能权限。已完全实现 ✅

### 角色不绑部门 ✅

角色全局存在，数据范围跟着用户的 dept_id 走。以实际代码验证为准。

---

## 三、关键原则：部门不直接关联功能权限 ✅

`sys_dept` 不写 Casbin、不分配功能权限。已实现并代码层面确保。
