## 目标与验收边界

商品主体接口已经使用统一 JSON 写协议。本批继续删除商品页面读链路中的展示加工、屏幕专用数据复制、页面 POST 写响应，使后台与后续业务区块可以复用业务数据。

本批不以改名为完成：把 PageResp 改名、把 controller 的展示代码搬到 service、另建 Go 展示包，都不满足目标。业务计算、事务、鉴权、分页查询和批量读取继续由后端负责；模板与 JavaScript 负责标签、格式、选中态、表单初值和局部结果展示。

任务开始时主工作区存在本任务之前的暂存变更。本任务在独立工作树内实施，不覆盖、撤销或提交那些变更；最终集成前重新核对冲突。

## 分工与依赖

- 主体子代理：商品列表、详情、新建、编辑，删除行展示对象与表单回显加工；保留批量事实读取。
- 分类子代理：分类、品牌、标签、属性，删除展示行与后端表单模板上下文。
- 定价子代理：预览统一 JSON，前端接收结果，台账消费原业务对象。
- 根代理：工程范围事实、公共命名出口、共享写结果扩展与 DTO 收口、详情模板/译文/发布记录、总体集成和门禁。

统一工程范围事实为 CatalogScope：工程原对象清单与有效 ProjectID。页面需要多份数据时使用 Objects(Object(name, value), ...) 进行纯命名传递，不生成新的屏幕数据副本。

## 验证要求

1. 商品 API 与浏览器 FormData 共享请求和业务服务；业务写响应统一 JSON。
2. 展示值与表单回显只在前端生成；列表、详情、编辑使用业务数据对象。
3. 列表批量读取及 SQL 次数约束保持，列表数量变化不引入逐行详情查询。
4. 真实模板渲染验证空态、数据态、分页、错误、中文/英文与表单字段。
5. go build、相关包与 feature 测试、check-all.sh；环境缺失与代码失败分别记录。
6. 收口旧类型、旧方法、过期注释、旧路由及门禁债务，不保留生产双轨。

## 实施结果

实现已收口，最终验证结果在下方记录。

- 商品列表、详情、新建、编辑、分类/品牌/标签/属性、调价、译文和发布记录删除整屏展示 DTO。后端按需返回原对象；标题、徽标、选中态、输入初值、评分小数和规格显示归前端。
- 页面通过 `pageview.Objects` 纯命名传递独立对象；查询失败统一走 JSON 错误出口。详情模板的正常未绑定由声明了 404 的事实识别，数据库故障继续上抛。
- 属性值编辑使用前端行模板，经唯一写基座提交 JSON 数组；DTO 绑定兼容实际 FormData 字符串与重复复选框值。
- 调价预览使用现有 `/api/product/pricing/preview` JSON 接口与 `registerResultHandler`。应用调价把价格、自动标签、审计与发布失效放进同一事务；锁等待后重新核对目标集合和当前成本，不能算出的条目整批拒绝。
- 变体清单在事务内锁读；重复行冲突返回可定位明细；库存事实一次读取，同时用于总量和仓库明细，读取失败不伪装成空库存。
- 写契约生成器跟踪真实泛型绑定；字段扫描器按 include/import/yield 和实际提交按钮展开字段，条件 required 不误判成无条件必填。不增加豁免。

## 后续调用方必须遵守的契约变更

| 位置 | 现行契约 | 调用方要求 |
|---|---|---|
| `GET /api/product/list` | `data` 为 `items/total/page/size` 分页结果 | 不再把 `data` 当商品数组；商品项复用业务对象 |
| 分类、品牌、标签、属性页面 | 页容量参数为 `size` | 翻页必须保留工程、关键词与筛选条件 |
| 变体组合预览 | `{code,message,data}`；`data.rows` 提供 `optionValues/optionKey/skuCode` | 规格文字由前端按属性定义显示；不恢复 `spec` 展示字段 |
| 发布尝试记录 | 原始时刻、耗时、次数、语言列表、结果状态 | 前端格式化；不向页面输出内部异常原文 |
| 仓库候选与译文候选 | 原始名称、编码、实体类型与字段标识 | 不恢复 `Label`、`FieldLabel` 等成品显示副本 |
| 调价应用、变体清单保存 | 整批事务；冲突在 `data.items` 定位 | 不恢复逐条提交或成功回执中的 skipped |
| 属性值保存 | `values` 为单个 JSON 数组 | 用 `data-write-json="values"` 保持数组；不声明单对象、不重新实现提交器 |

业务区块或新的页面可以消费这些查询对象。页面/区块的编排仍由前端和构建层负责，本批没有新增访客运行时模板解释入口。
