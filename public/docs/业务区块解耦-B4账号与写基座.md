# B4：账号 JSON 与唯一写基座

本批将账号组件的十个运行时 HTML 能力改成构建期静态表单与访客 JSON 接口。既有 `/user` 页面路由暂时保留；新构建产物不依赖它们返回 HTML 或重定向。

## 分层

| 范围 | 层 | 结果 |
| --- | --- | --- |
| user dto/service | 请求、事实与业务服务 | 复用认证、资料、偏好和设备业务；媒体字段复用可信完整 URL；不回 HTML、导航和格式化时间 |
| user inbound/http | 访客 JSON 出口 | 绑定请求、覆盖当前访客身份、调用 service、返回统一 JSON |
| userForms 与 site-user.js | 构建组件和前端 | 静态九模式表单、当前实例模式切换、时间显示、失败输入保留 |
| write-base.js | 唯一写基座 | 统一提交、CSRF、成功处理、导航与预览阻写 |
| 旧 runtimefragment | 删除旧形状 | 删除账号十个注册、模板、专用依赖和标签；保留通用协议安全测试 |

## 访客接口

只读接口为 `GET /api/site/user/session`、`/account`、`/sessions`。写接口统一为 `POST /api/site/user/login`、`/register`、`/forgot`、`/reset`、`/logout`、`/account/profile`、`/account/preference`、`/account/password`、`/sessions/revoke`、`/sessions/revoke-others`。

账号和设备读取要求当前访客登录，未登录返回 JSON 401。后台会话不能充当访客身份。客户端提交的用户 ID、注册 IP 等身份事实不作为信任来源。

首次只读 JSON 请求通过 `X-CSRF-Token` 响应头取得独立访客 CSRF。写基座仅从访客数据基座读取该值，不读取后台页面的 CSRF meta，不将凭据写入静态产物。登录令牌只写安全 cookie；登录时轮换 CSRF。私有读取使用 `Cache-Control: no-store`。

设备 ID 是当前会话派生的不透明 HMAC 句柄。原始令牌和会话存储哈希不对外输出；撤销只能匹配本人的非当前设备。账号时间使用毫秒事实，由前端格式化。资料和偏好各自的语言、时区字段分开回填，避免同名字段覆盖另一份存储事实。

## 写成功处理契约

组件通过 `WBUI.writeBase.registerResultHandler(name, fn)` 注册具名处理器，在表单声明 `data-write-handler`。同一名称只注册一次；重复脚本初始化复用已经存在的基座和组件注册，不新增提交监听。

处理器收到 `{form, submitter, data, payload, text, instanceId}`。`instanceId` 来自最近的 `data-component-instance` 根节点。返回 `true` 接管当前写操作的局部更新和导航，不再派发通用成功事件；返回 `false` 继续原成功事件和导航流程。这样一次写只有一个结果处理入口。

`data-write-handler` 与 `data-write-reload` 互斥。声明冲突或能力未注册时在请求前明确拒绝，不发送请求。401、非 JSON 和 HTML 登录页均不当作成功；失败不清空用户输入、不调用成功处理器，也不跳转到后台登录页。

账号注册名为 `user.forms`。它仅处理相同实例的账号表单。登录配置明确的安全站内目标时由前端导航；否则切换当前实例到账号面板。资料读取完成前禁用提交，刷新不覆盖已经编辑的表单。密码仅在成功后清空。

## 编辑预览

统一文档出口在临时编译上下文输出 `site-preview-mode=readonly` meta 与可见的模拟预览提示；正式发布不输出此标记，Document Props 不能开启它。

写基座在网络请求前拦截该上下文内的 JSON 写、原生非 GET 表单和 HTMX 写，保留输入并提示不会提交真实数据。作者模拟状态和完整页面动作配置属于后续 B7/B10 收口，不通过真实注册、改密或下单演示状态。

## 验证

覆盖真实生产迁移 PG 与 Redis 的 JSON/FormData 链路、访客和后台身份隔离、CSRF 轮换、错误状态、多设备不透明撤销、头像历史相对地址与域名切换。Node 测试覆盖一次提交、处理器接管或默认导航、注册重复、reload 冲突、401/HTML 失败、输入和焦点保留、实例隔离及预览零写请求。九种模式通过真实构建和模板渲染测试；迁移 681 的四条双语词条逐项登记并通过 PREPARE 校验。
